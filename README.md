# Box Of Jacks

<img src="logo.png" alt="Логотип Box Of Jacks" width="132">

Личный лаунчер для вечеринок на Windows. Используйте строго с купленными версиями Jackbox Party Packs

## Как начать играть

Понадобятся Windows x64, .NET 9 Desktop Runtime и локальный диск NTFS.

1. Откройте [Releases](https://github.com/pascal-enjoyer/BoxOfJacksLauncher/releases/latest). Скачайте `BoxOfJacks.exe` и все ZIP-файлы с данными. Распакуйте ZIP-файлы в папку с лаунчером и запустите `BoxOfJacks.exe`.
2. Выберите игру. Если появится код комнаты, участники смогут подключиться по инструкции на экране.

Jackbox и игровые материалы принадлежат их правообладателям. Это личный независимый проект.
