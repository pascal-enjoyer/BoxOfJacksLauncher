# Box Of Jacks

<img src="logo.png" alt="Логотип Box Of Jacks" width="132">

Личный лаунчер для вечеринок на Windows. Используйте строго с купленными версиями Jackbox Party Packs

## Как начать играть

Понадобятся Windows x64, .NET 9 Desktop Runtime и локальный диск NTFS.

1. Скачайте `BoxOfJacks.exe` из раздела [Releases](https://github.com/pascal-enjoyer/BoxOfJacksLauncher/releases/latest) и запустите его.
2. Откройте настройки, отметьте **«Режим разработчика»** и подтвердите включение.
3. Нажмите **«Скачать игры»** и введите пароль. Откроется каталог с превью: отметьте нужные игры и нажмите **«Скачать выбранное»**. Внизу видно, сколько места займёт загрузка вместе с нужным движком.
4. Чтобы добавить игры позже, снова нажмите **«Скачать игры»**: установленные игры отмечены, докачиваются только новые.
5. Выберите игру. Если появится код комнаты, участники смогут подключиться по инструкции на экране.

Jackbox и игровые материалы принадлежат их правообладателям. Это личный независимый проект.
